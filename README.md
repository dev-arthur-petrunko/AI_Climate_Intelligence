## ✨ Overview

Climate Intelligence is a premium web platform for monitoring Earth's climate in real time. It pairs a full-screen interactive **3D Earth globe** with a live data dashboard, interactive analytics, and AI-powered forecasts — in a dark, glassmorphic interface inspired by mission-control systems.

The interface is available in **7 languages** (🇬🇧 🇺🇦 🇩🇪 🇵🇱 🇫🇷 🇮🇹 🇬🇪) with no authentication required.

### Key Features

- 🌐 **Interactive 3D Earth Globe** — full-screen WebGL rendering with climate layers (temperature, CO₂, methane, wildfires, ice, rainfall, wind, pollution), atmospheric glow, clouds, and a star field
- 📊 **Live Climate Metrics** — real KPI data: temperature anomaly, CO₂ concentration, sea ice extent, air quality, and more
- 🔥 **Live Event Feed** — global climate events (wildfires, cyclones, volcanic activity, extreme weather) positioned on the globe
- 📍 **Rich Fire Tooltips** — every fire hotspot shows FRP (radiative power), confidence, satellite name and a human-readable nearest-city location (reverse geocoding, ~60 cities worldwide)
- 💬 **Event Tooltips** — hovering a marker explains what the event is, with descriptions localized in all 7 languages
- 📱 **Responsive Design** — adapts to phone, tablet and laptop: side panels auto-open on desktop and collapse into compact buttons on mobile
- 🤖 **AI Predictions** — forecasts generated by **AI Groq** with probability scores, confidence intervals, and risk assessments across multiple timeframes
- 📈 **Interactive Analytics** — historical trends and climate data visualization with Plotly.js
- 🧠 **AI Analysis Panel** — popup on the right of the globe with today's climate situation analysis, regenerated twice a day (09:00 & 17:00 Kyiv) by AI Groq in your language
- 🌌 **Space & Asteroid Panel** — live geomagnetic Kp, solar flares, CMEs, Kp forecast, and near-Earth asteroid approaches on the left of the globe
- 🌙 **Aurora Dark Theme** — deep-space palette with emerald / violet / pink accents
- 🌍 **7 Languages** — English, Ukrainian, German, Polish, French, Italian, Georgian

## 🚀 Quick Start

### Prerequisites

- **Node.js** 18+ and npm
- **Python** 3.10+

### 1. Clone

```bash
git clone https://github.com/dev-arthur-petrunko/AI_Climate_Intelligence.git
cd AI_Climate_Intelligence
```

### 2. Backend (FastAPI)

```bash
cd backend
python -m venv venv

# Activate
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt
python main.py
```

Backend runs at `http://localhost:8000` · interactive docs at `http://localhost:8000/docs`

### 3. Frontend (Next.js)

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at `http://localhost:3000`

## 🔌 API Reference

All endpoints live in `backend/main.py` and return JSON.

### Core Dashboard

| Endpoint | Description |
|----------|-------------|
| `GET /` | API information |
| `GET /api/health` | Health check |
| `GET /api/kpi` | Live KPI metrics |
| `GET /api/events` | Current global climate events with `[lon, lat]` coordinates; fires include `frp`, `confidence`, `satellite` and a human-readable nearest-city `location` |
| `GET /api/predictions` | AI-generated climate predictions (Groq) |
| `GET /api/ai-analysis` | Today's AI climate analysis (Groq, 09:00 & 17:00 Kyiv, per language) |
| `GET /api/ai-summary` | AI climate summary |
| `GET /api/overview?lat=..&lon=..` | Aggregated snapshot |

### Live Data Sources

| Endpoint | Data | Provider |
|----------|------|----------|
| `GET /api/weather?lat=..&lon=..` | Temperature, humidity, wind, pressure | Open-Meteo |
| `GET /api/marine?lat=..&lon=..` | SST, wave height/period/direction | Open-Meteo Marine |
| `GET /api/air-quality?lat=..&lon=..` | AQI, PM2.5, PM10, O₃, NO₂, CO | Open-Meteo Air Quality |
| `GET /api/gistemp` | Global temperature anomaly since 1880 | NASA GISTEMP |
| `GET /api/co2` | Global monthly CO₂ since 1958 | NOAA GML |
| `GET /api/sea-ice` | Sea ice extent & anomaly | NSIDC |
| `GET /api/sea-ice-south` | Antarctic sea ice extent & anomaly | NSIDC |
| `GET /api/sea-level` | Global mean sea level trend | Church & White + UHSLC (OWID) |
| `GET /api/ocean-heat` | Ocean heat content, 0–2000 m | NOAA GML (OWID) |
| `GET /api/ocean-ph` | Ocean acidification (surface pH) | NOAA / OWID |
| `GET /api/hurricanes` | Active tropical cyclones | NOAA NHC |
| `GET /api/fires?days=1` | Active wildfire hotspots | NASA FIRMS ⚠️ needs key |

> **Wildfires** require `FIRMS_API_KEY` in `backend/.env`. If a provider is unreachable or a key is missing, the backend degrades gracefully to cached or fallback data so the dashboard always renders.

### Example Response

```json
{
  "name": "Global Temperature",
  "value": "+1.54°C",
  "trend": "+0.12°C",
  "trend_up": true,
  "insight": "Temperature anomaly continues upward trend"
}
```

## ⚙️ Configuration

Create `backend/.env` from the template:

```bash
cp backend/.env.example backend/.env
```

| Variable | Purpose |
|----------|---------|
| `FIRMS_API_KEY` | NASA FIRMS key for live wildfire hotspots (optional) |
| `DATABASE_URL` | PostgreSQL connection string (optional) |
| `DATABASE_POOL_SIZE` | Connection pool size (optional) |
| `GROQ_API_KEY` | Groq API key for AI analysis & predictions (free at [console.groq.com](https://console.groq.com/keys)) |
| `GROQ_MODEL` | Groq model for AI analysis & predictions (default: `llama-3.3-70b-versatile`) |

Create `frontend/.env.local` to point the UI at your backend:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```
